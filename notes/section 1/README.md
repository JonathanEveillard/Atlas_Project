# Requirements

As for the requirements, there are main components that you will need and there are optional components which you can get to help you have better control over your build.

## Clustered Proxmox (2 Devices | optional)
- Device 1 (pve1 | Main proxmox)
    - Intel I7 (Minimum Intel I5)
    - Nvidia RTX 3060 (Optional, require any Nvidia RTX <=3060 for AI services)
    - 128GB of Memory/RAM (Minimum 16GB Memory/RAM)

- Device 2 (pve2 | Second proxmox, optional)
    - Mac Intel 2018 (Optional) OR BELOW, NOT BOTH
    - Any Device with following specs
        - Intel I5 Minimum
        - 8GB of Memory Minimum
        - Integrated GPU

## Network Accessories
-   Protectli Vault FW4B - 4 Port OR any mini pc with 4 NIC (Baremetal Firewall)
- TP-Link Omada WIFI 6 AX3000 OR any Mount Wireless Access Point (WAP for Internal communication)
- TP-Link 8 port TL-SG108E OR any 8 port PoE Switch (Switch for LAN communication)
